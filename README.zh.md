# U-MA Hanon

在浏览器中练习夏尔-路易·哈农《钢琴技巧练习》（The Virtuoso Pianist）全部 60 首：在五线谱上看谱，看到**双手放在键盘上**、每根手指都标有编号，按你选的速度聆听；接上 MIDI 键盘，应用还会听你弹并分析你的演奏。

**▶ 打开应用：** https://buenosairesfront.github.io/hanon/

无需安装。界面为西班牙语。

## 使用方法

1. **选择练习。** 60 首按原书三部分分组：**I · 1–20** 预备练习（洋红）、**II · 21–43** 进阶（青色）、**III · 44–60** 炫技（黄色）。点击键盘下方的编号，或点击顶部的大编号打开 1–60 完整网格。
2. **选择变体**（如有）：音阶（39）和琶音（41）按原书顺序提供全部 24 个调（每个大调后接其关系小调；小调有和声与旋律两种），半音阶（40）有 8 种音程和方向，同音反复（45）有 6 种指法，断奏三度或六度（48）等。
3. **看谱。** 两行五线谱显示练习：**↑ 上行**（青色）和 **↓ 下行**（洋红）。手机上用标签切换。
4. **看手。** 键盘是应用的核心。双手连同手掌画在琴键上，每根手指显示编号（1 = 拇指 … 5 = 小指，各有颜色），虚线轮廓标出**下一个手位**。键盘下方每只手一行，显示当前组的指序，并点亮正在发声的音。
5. **播放。**
   - **▶ 两遍**：只含前两组和最后两组的简短示范，快速听出形状。
   - **↑ 上行** / **↓ 下行**：只播一个方向。
   - **↑↓×2**：完整练习两遍。
   - **loop** 循环播放，直到按 **stop**。
6. **调整速度**：用滑块或 – / + 在 40–160 BPM 之间调节。下方黄色条标出哈农建议的范围（60 → 108）：从慢开始，逐步加快。节拍器 **MET** 按练习的拍号（2/4、3/4、4/4 或 6/8）闪烁并发声，重拍为洋红色。

## 用 MIDI 键盘练习

按 **MIDI** 并允许访问。之后：

- 你按下的键会在屏幕键盘上亮起青色；
- **REC** 会播放练习作为引导，同时录下你弹的内容；
- 结束后显示**演奏分析**：准确度（%）、平均偏差（毫秒）、均匀度（%）和错音；每个音的时间图（提前 ↓ / 落后 ↑），每根手指的延迟和力度，以及双手的力度变化（右手在上，左手在下）。

没有 MIDI 时，按 **新的示例演奏** 可以看看分析的样子。

## 浅色与深色

**浅色 / 深色** 按钮切换主题；选择会保存在该浏览器中。

## 内部原理

一个没有依赖的 `index.html`：练习不是逐音存储的，而是**生成**的。每首是一个旋律单元（以音阶级数表示）加上双手的指法；引擎每小节把它上移一级，再移回来，并为每个音写上正确的变音记号（半音阶上行用升号、下行用降号）。音阶、琶音和八度练习按传统指法为全部 24 个调构建。乐谱用 SVG 绘制，键盘和分析用 `<canvas>`，声音和节拍器用 Web Audio，键盘输入用 Web MIDI。

## 本地运行

下载 `index.html` 直接打开，或用静态服务器：

```
python3 -m http.server 8000
```
