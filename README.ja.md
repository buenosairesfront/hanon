# U-MA Hanon

シャルル＝ルイ・アノンの『ピアノの名手』全 60 曲をブラウザで。五線譜で見て、**両手が鍵盤の上に**指番号つきで描かれ、好きなテンポで聴けます。MIDI キーボードをつなげば、アプリがあなたの演奏を聴いて分析します。

**▶ アプリを開く：** https://buenosairesfront.github.io/hanon/

インストール不要。画面はスペイン語です。

## 使い方

1. **練習曲を選ぶ。** 60 曲は本の 3 部に分かれています：**I · 1–20** 準備（マゼンタ）、**II · 21–43** 上級（シアン）、**III · 44–60** 名人芸（イエロー）。鍵盤の下の番号をタップするか、上の大きな番号をタップすると 1–60 の一覧が開きます。
2. **バリエーションを選ぶ**（ある曲のみ）：音階（39）と分散和音（41）は本の順番どおり全 24 調（長調のあとに平行短調、短調は和声的・旋律的）、半音階（40）は 8 種類の音程と方向、同音連打（45）は 6 種類の運指、スタッカートの 3 度・6 度（48）など。
3. **楽譜を読む。** 2 段の五線で表示：**↑ 上行**（シアン）と **↓ 下行**（マゼンタ）。スマホではタブで切り替えます。
4. **手を見る。** 鍵盤がアプリの中心です。両手が手のひらごと鍵盤の上に描かれ、指ごとに番号（1 = 親指 … 5 = 小指、色分け）が付き、点線の輪郭が **次の手の位置** を示します。鍵盤の下には片手ずつ現在のグループの指順が並び、鳴っている音が光ります。
5. **鳴らす。**
   - **▶ 2 回**：最初と最後の 2 グループだけの短いデモ。形をすばやくつかめます。
   - **↑ 上行** / **↓ 下行**：片方向だけ。
   - **↑↓×2**：曲全体を 2 回。
   - **loop** は **stop** まで繰り返します。
6. **テンポ** はスライダーか – / + で 40〜160 BPM。下の黄色い帯はアノンが指定する範囲（60 → 108）。ゆっくり始めて少しずつ上げましょう。メトロノーム **MET** は曲の拍子（2/4、3/4、4/4、6/8）で点滅・発音し、強拍はマゼンタ。

## MIDI キーボードで練習

**MIDI** を押してアクセスを許可すると：

- 弾いた鍵が画面の鍵盤でシアンに光ります。
- **REC** は手本を鳴らしながら、あなたの演奏を録音します。
- 終わると **演奏の分析** が表示されます：正確さ（%）、平均のずれ（ms）、均一さ（%）、ミス。各音のタイミング（早い ↓ / 遅い ↑）のグラフ、指ごとの遅れと強さ、両手の強弱（右手が上、左手が下）。

MIDI がなくても **新しいサンプル演奏** で分析の見え方を確認できます。

## ライト／ダーク

**ライト / ダーク** ボタンでテーマを切り替え。選択はそのブラウザに保存されます。

## 中身

依存関係のない `index.html` ひとつ。練習曲は音符を 1 つずつ保存しているのではなく **生成** しています。各曲は音階の度数で書かれた旋律の細胞と両手の運指で、エンジンがそれを 1 小節ごとに 1 度ずつ上げて戻し、各音を正しい臨時記号で記譜します（半音階では上行は ♯、下行は ♭）。音階・分散和音・オクターブの練習は伝統的な運指で全 24 調に組み立てます。楽譜は SVG、鍵盤と分析は `<canvas>`、音とメトロノームは Web Audio、鍵盤入力は Web MIDI。

## ローカルで動かす

`index.html` をダウンロードして開くか、フォルダを配信します：

```
python3 -m http.server 8000
```
